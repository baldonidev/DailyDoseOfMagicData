# Daily Dose of Magic — Card Data

This repository contains preprocessed card data published automatically by the
[Daily Dose of Magic](https://github.com/baldonidev/DailyDoseOfMagic) iOS app pipeline.

## Purpose

This data is exclusively for use by the **Daily Dose of Magic iOS app**. It is
not intended to be consumed directly or redistributed by other applications,
services, or projects.

Card data and images are sourced from [Scryfall](https://scryfall.com) under the
[Wizards of the Coast Fan Content Policy](https://company.wizards.com/en/legal/fancontentpolicy).
Magic: The Gathering card images and oracle text are © Wizards of the Coast.
